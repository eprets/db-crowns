# Crown DB — UAV Tree Crown Database

## Описание проекта

Проект предназначен для формирования базы данных параметров крон деревьев по изображениям, полученным с БПЛА.

Основная задача системы — привести изображения крон деревьев, полученные в разных условиях съёмки, к единому стандартизированному представлению.

Система реализует:

- импорт изображений и метаданных;
- аннотацию крон деревьев;
- хранение эллипсов и масок;
- нормализацию по высоте;
- нормализацию масштаба;
- синтез недостающих уровней высоты;
- экспорт высотного профиля дерева;
- визуализацию результатов.

---

# Основные проблемы

Проект учитывает следующие проблемы:

- разные высоты съёмки;
- разные дни года;
- разное время суток;
- разные координаты;
- разные камеры;
- присутствие посторонних крон;
- отсутствие изображений на части высот.

---

# Pipeline системы

```text
Блок 1: Метаданные -> набор изображений
        ↓
Блок 2: Аннотация изображений
        ↓
Блок 3: ROI + описание кроны
        ↓
Блок 4: Приведение к единой сетке высот
        ↓
Блок 5: База данных
        ↓
Блок 6: API / экспорт / интерфейс
        ↓
Блок 7: Пользователь

Блок 8: Синтез изображений
        ↑
        └──── обратно в Блок 4
```

# Формат представления кроны

Крона дерева хранится в двух формах:

## 1. Эллипс

Параметры:

- x0
- y0
- a
- b
- theta

Используется для:

- стандартизированного описания;
- вычисления признаков;
- анализа;
- ML.

## 2. Маска

Используется для:

- точной формы кроны;
- сегментации;
- обучения нейросетей;
- оценки качества синтеза.

---

# Сетка высот

Используется фиксированная сетка высот:

```text
0, 5, 10, 15, 20, 25, ...
```

Все наблюдения приводятся к этой сетке.

---

# Синтез изображений

Для заполнения отсутствующих уровней используются:

- linear blend;
- Pix2Pix;
- (в перспективе) diffusion models.

Синтезированные уровни помечаются как:

```text
data_type = SYNTH
```

Реальные уровни:

```text
data_type = REAL
```

# Основные команды

## Импорт данных

```bash
python -m app.main import-images
```

## Построение уровней

```bash
python -m app.main build-levels
```

## Нормализация изображений

```bash
python -m app.main normalize-scale
```

## Pix2Pix синтез

```bash
python -m app.main apply-pix2pix tree_001 60 --allow-far
```

## Синтез всех пропусков

```bash
python -m app.main apply-pix2pix tree_001 --all-missing --allow-far
```

## Построение масок

```bash
python -m app.main build-ellipse-masks
python -m app.main build-roi-masks
python -m app.main normalize-masks
python -m app.main synthesize-masks
```

## Экспорт профиля дерева

```bash
python -m app.main export-tree-profile tree_001
```

## Визуализация

```bash
python -m app.main make-tree-preview tree_001
```

## Проверка состояния проекта

```bash
python -m app.main project-status tree_001
```
